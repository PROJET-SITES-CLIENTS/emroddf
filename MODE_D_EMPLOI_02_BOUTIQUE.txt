        EMROD SARL — MODE D'EMPLOI : 02 - LA BOUTIQUE (CATALOGUE)
========================================================================

Ce document vous explique comment ajouter, modifier ou supprimer des 
meubles et des catégories dans la boutique en ligne.

------------------------------------------------------------------------
OÙ SE TROUVE LE DOSSIER ?
------------------------------------------------------------------------
Connectez-vous à votre Drive et ouvrez le dossier nommé "Emrod Meubles" 
(ou "Catalogue") (ID : 1yisVYsJBiyyYeP9DEg8d-BbXxPJ0Hwju).

------------------------------------------------------------------------
STRUCTURE OBLIGATOIRE (TRÈS IMPORTANT)
------------------------------------------------------------------------
Le site fonctionne avec la hiérarchie suivante à 3 niveaux :
1. Dossier principal : "Emrod Meubles"
2. ↳ Dossier de Catégorie : (ex: "Salon", "Chambre", "Bureau")
3. ↳ ↳ Dossier du Produit : (ex: "Canapé 3 places", "Table basse")
4. ↳ ↳ ↳ Images : Les photos du produit à l'intérieur.

(Note : Le site récupère automatiquement la liste de vos Catégories. 
Cependant, le site masque de manière intelligente les catégories et les 
produits qui sont entièrement vides pour éviter les pages blanches.)

------------------------------------------------------------------------
AJOUTER UN NOUVEAU MEUBLE SUR LE SITE
------------------------------------------------------------------------
1. Dans le dossier "Emrod Meubles", ouvrez (ou créez) le dossier de la 
   CATÉGORIE dans laquelle vous voulez placer le produit (ex: "Salon").

2. À l'intérieur de cette catégorie, créez un SOUS-DOSSIER. 
   Le nom de ce sous-dossier sera le NOM EXACT DU PRODUIT sur le site.

3. Ouvrez le dossier du produit et glissez-y toutes les photos de ce 
   meuble (vue de face, détails, etc.).

4. Choisissez la photo principale (celle qui s'affichera en premier).
   Faites un clic droit dessus > "Informations" > "Détails" (le bouton "i").

5. Dans le panneau de droite, tout en bas, dans le champ "Description",
   copiez et collez le MODÈLE EXACT ci-dessous :

------------------------------------------------------------------------
MODÈLE À COPIER-COLLER (Modifiez avec vos informations)
------------------------------------------------------------------------
Prix: 450000 GNF
Dimensions: 120cm x 60cm x 40cm
Finition: Vernis mat
Essence: Bois Iroko
Description: Superbe meuble en bois massif avec finitions sur mesure. Les poignées sont en laiton vieilli pour un rendu industriel. Idéal pour votre intérieur.
------------------------------------------------------------------------
(⚠️ Le site lira automatiquement toutes ces informations. Le "Prix:" est indispensable pour calculer l'acompte de 60%).

------------------------------------------------------------------------
MODIFIER UN MEUBLE OU UNE CATÉGORIE
------------------------------------------------------------------------
* Changer le NOM d'un produit : Renommez le dossier du produit.
* Changer la CATÉGORIE d'un produit : Déplacez le dossier du produit 
  vers un autre dossier de catégorie.
* Changer le PRIX ou la DESCRIPTION : Modifiez la description de la 
  photo principale dans les détails de Google Drive.
* Ajouter/supprimer des photos : Ajoutez ou supprimez les images dans 
  le dossier du meuble.

------------------------------------------------------------------------
SUPPRIMER UN MEUBLE DU SITE
------------------------------------------------------------------------
Supprimez simplement le dossier de ce produit, ou mettez-le dans
la corbeille. Il disparaîtra automatiquement de la boutique.
